# convention des commits du projet InterLocal

## Format
<type>(<scope>): <description courte>

## Types autorisés
- feat     : nouvelle fonctionnalité
- fix      : correction de bug
- docs     : documentation
- style    : formatage du code
- refactor : refactoring
- test     : ajout de tests
- chore    : maintenance

## Exemples
feat(api): ajouter endpoint de suivi livraison
fix(auth): corriger validation du token JWT
docs(readme): mettre à jour instructions installation
